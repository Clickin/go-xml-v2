# XML reader benchmark: darwin/arm64 (Apple M4)

One 16 MiB document, read by the current `encoding/xml`, by `encoding/xml` under `GOEXPERIMENT=xmlv2`, by the new tokenizer (`encoding/xml/xmltext`) and by readers in other languages. The `encoding/xml` rows are the numbers in the `GOEXPERIMENT=xmlv2` issue. A Korean write-up with per-commit history is in `README.ko.md`.

## Results

Apple M4, 16 GB, macOS. Go built from the `xml-v2-poc` branch at 75affe4032 (`go1.28-devel`, default `GOGC`). Each case: 3 warmups, 10 timed runs in one process, median. Each timed run reads the file and parses it.

| `encoding/xml` `Decoder.Token`, current | 171.33 ms | 93.4 MiB/s | 3,125,805 |
| `encoding/xml` `Decoder.Token`, `GOEXPERIMENT=xmlv2` | 71.07 ms | 225.1 MiB/s | 1,360,747 |
| `encoding/xml` `Unmarshal`, current | 228.37 ms | 70.1 MiB/s | 4,600,377 |

All readers produce the same event count (967,965) and checksum (36,104,832). Raw samples are in `results/`.

## Method

- **Input.** `runtime-comparison-16mib.xml` (16,777,038 bytes, ASCII, no namespaces or entities), generated by `packages/benchmark/runtime-matrix.mjs` in [Clickin/stax-xml](https://github.com/Clickin/stax-xml) at 07cca8a0. SHA-256 `1285dbb0d198c4c5e579faa626f7ef02b0b279b1182d37d4039f3acb5929d7d4`.
- **Checksum.** Every start and end element name, every attribute name and value, and each run of non-whitespace text is folded into one checksum. The rules follow `packages/benchmark/reader-cross-runtime.mjs` in stax-xml; `main.go` implements them for Go.
- **quick-xml, checks on.** Same reader as the stax-xml harness, but doing the work `xmltext` does: UTF-8 checks on names (`std::str::from_utf8`), references resolved in attribute values (`unescape_value()`) and text (`resolve_char_ref`/`resolve_xml_entity`), end-name checks on (the default). It still does less than `xmltext`: no XML name-character rules, no `Char` range check, no duplicate-attribute check.
- **quick-xml, raw bytes.** The stax-xml harness as is: no UTF-8 check, no reference resolution, no end-name check, names left as bytes.

## Limits

- One document, one machine. Rankings may differ on documents with namespaces, entities, large text or long attribute lists.
- Runs are warm (JIT and caches warmed in one process), with default JVM and Go GC settings.
- The arm64 and amd64 runs (`../windows-amd64`, `../linux-amd64`, `../small-ab`) use different inputs, Woodstox and quick-xml versions and settings, so compare ratios within one machine only.

## Running it again

Build Go from the `xml-v2-poc` branch, then:

```sh
GO=/path/to/xml-v2-poc/bin/go
F=/path/to/stax-xml/packages/benchmark/test-data/runtime-comparison-16mib.xml
OUT=$PWD/results
# Node / Java / Rust (raw bytes), from stax-xml
(cd /path/to/stax-xml/packages/benchmark && node reader-cross-runtime.mjs --runs 10 --warmups 3 \
  --json-out $OUT/others.json --md-out $OUT/others.md)
# quick-xml, checks on
cargo run -q --release --manifest-path quickxml-checked/Cargo.toml -- $F 3 10 > results/quickxml-checked.json
# Go, from this directory
GOEXPERIMENT=xmlv2 $GO run . -file $F -warmups 3 -runs 10 > results/go-xmlv2.json
$GO run . -file $F -warmups 3 -runs 10 > results/go-none.json
```

The path in `results/others.json` was shortened to `~/github/stax-xml`.
